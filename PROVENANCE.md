# Provenance

The mathematical source is Paul Bankston, *Metric Topology: A First Course*
(Marquette University, Spring 2011), Propositions 29.1 and 29.2, printed pages
91 and 92, and Exercise 29(6), page 93. The source is available from
[the author's university website](https://www.mscsnet.mu.edu/~paul/Paper/4450102text.pdf#page=91).
The statements use Hausdorff continua and do not require metrizability.
The author has not been contacted about this formalization.

The formal proof generalizes the closed-side argument used for singleton
cuttings in the earlier non-cut-points project by the same credited authors.
That earlier local Solution source was read as ordinary text. This project
imports no module from it. The generalized gluing lemma has a connected closed
set in place of a point and follows Bankston's Proposition 29.1.
